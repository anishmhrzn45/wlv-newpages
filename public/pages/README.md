# WebLiveView Static HTML Pages

This folder contains static HTML and CSS versions of the WebLiveView pages for export, sharing, or static hosting purposes.

## Files Included

- **styles.css** - Global stylesheet with brand colors, typography, and components
- **index.html** - Home page
- **about.html** - About Us page
- **pricing.html** - Pricing plans page
- **contact.html** - Contact page
- **signup.html** - Sign up page

## Brand Colors

- **Navy**: `#0F2847` (Primary brand color, headings)
- **Pink**: `#F12768` (CTA buttons, accents)
- **Light**: `#F9FAFB` (Backgrounds, sections)
- **Gray**: `#4A4A4A` (Body text)
- **Accent Blue**: `#7FA7D5` (Secondary accents)

## Fonts

All pages use **Poppins** font family from Google Fonts.

## Assets

Images are referenced from the parent public folder:
- `../webliveview-logo.png`
- `../hero-image.jpg`

## Usage

These HTML files can be:
1. Opened directly in a browser
2. Uploaded to static hosting services
3. Used as email templates or landing pages
4. Shared with stakeholders for review

## Note

These are static HTML versions. The main React application in `/src` is the interactive version with full functionality.
